Privacy

This site has no accounts, no forms, no cookies, no analytics and no advertising. Nothing on it loads from anywhere else.

On your device

If you drag the reading column wider or narrower, your browser keeps that width under the name page-column-width, so the page opens the same way next time. It never leaves your device; clearing this site's data removes it.

On the server

Each request is logged with its path, method, status, size and duration and a request identifier. Your IP address and query strings are not logged. The logs stay on the server, rotate away on their own, and are not shared.

In front of the server

A network service delivers and protects this site. To do that it processes connection data, including your IP address.

Questions

Open an issue at github.com/snaraj/naranjo.online. Report a security problem privately at github.com/snaraj/naranjo.online/security.
